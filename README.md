# とびだすなかみ計算ツール
ポケモンの特性「とびだすなかみ」に関する計算をするWebツールです。

## 公開URL
https://tobidasunakami-calculator-1.onrender.com/

## 概要
特性「とびだすなかみ」のポケモン、特にメガウツボットを使用している際、特性の効果で相手のポケモンの体力を削ることがよくあると思います。
しかし、体力を削って終わりなのではなく、その後裏のポケモンで削られた相手のポケモンの相手をする必要があるため、「とびだすなかみ」のダメージ量で相手のポケモンのhp努力値調整が予測できたら役に立つだろうと考えました。
そこで、相手のポケモン,hp割合,とびだすなかみのダメージ量を入力することで、対戦中でも予測できるこのWebツールを製作しました。
他にも、相手のポケモン,hp割合から相手のポケモンの残り体力を予測したり、相手のポケモン,相手のポケモンのa種族値から技「ちからをすいとる」の回復量を予測したりする機能も搭載してあります。

## 使用技術
- Python
- Flask
- HTML
- CSS
- JavaScript
- PokéAPI

## 開発環境
Pythonを使用して計算処理を作成し、Flaskを利用してWebアプリケーションとして実装しました。
HTML・CSS・JavaScriptを使用してWebページの表示や入力操作を実装しています。
また、PokéAPIからポケモンの種族値を取得しています。

##工夫した点
このWebツールは、対戦中の限られた時間に使用できるようにする必要があるため、入力欄をシンプルにしたり、ポケモン名の予測変換機能を実装して素早く目当てのポケモンを表示できるようにしたりと、操作面に工夫を行いました。

## スマートフォンへの対応
PCだけでなく、スマートフォンからも利用できるように画面サイズに合わせてレイアウトを調整しています。
